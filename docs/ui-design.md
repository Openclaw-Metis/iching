# 圖錄式介面設計與驗收

日期：2026-10-25。基準提交：`28d637a`。

## 設計方向

使用 Taste Skill 的 app screen 流程。選用 **True-black flat**，seed **379881689**，保留既有墨黑、古董金與 Noto Serif TC。品牌特色來自卦牌圖像、卦畫與經文；一般操作改用中性表面、系統字體與白底黑字主按鈕。

核心概念：六十四張卦牌成為可操作的圖錄。選中一卦，就在旁邊讀卦辭、觀察卦畫與錯綜互卦關係，再進入完整經文。手機保留兩欄卦牌與摘要列。

抽樣時有兩次重抽：

1. 外殼由 Ruled T-frame 改為 No sidebar。專案只有五個導覽入口，沒有帳戶或工作區切換，側欄會壓縮真正需要空間的卦牌。
2. 列表由 Count cards filters 改為 Table with tabs/filter bar。現有四種排列是觀看同一批卦的方式，不能虛構四組統計數字配合版型。排列控制搭配圖錄，沒有硬改成資料表。

## 專案自己的素材與限制

- 六十四張完成的 5:7 卦牌與統一牌背，沿用原有素材，不另生成圖片。
- 卦牌背景由上卦、下卦面板組合，可在八乘八矩陣比較。
- 文王卦序、上下卦、京房八宮、十二消息共四種排列。
- 錯、綜、互是實際卦象關係，預覽與連結皆由資料計算。
- 乾至未濟六十四卦的原典，依 `textOf(n)` 取用。
- 450 條白話經文，保留按需載入與原文切換。
- 三錢、親手分蓍、一鍵大衍與手動輸入的既有占卜流程。
- 每天固定一張今日卦，可記心得並自動保存。
- 八站、二十四課、八場考核，以實際八卦卦畫呈現站點。
- 修為、XP、每日目標與完成狀態皆取自本機資料。
- 本機保存、備份與離線機制照常；沒有新套件或資料結構變動。
- 溫故、收藏與行事曆提醒入口維持關閉。

## 截圖檢討

第一輪最明顯的三個問題是手機被舊媒體規則覆蓋成四欄、縮圖字級偏小，以及桌機預覽過高。已移除衝突規則，改為兩欄與 13px 說明，縮小預覽圖片並整理上下間距。同步修正奶油白與未實際載入的系統字型名稱警告。最後再縮短手機圖錄上方間距，並對齊學堂標題與內容。

依 app screen 的七個問題逐項檢查：

1. 最大區塊是實際卦牌；各頁的主要操作與資料先出現，沒有新增行銷式 hero。
2. 版頭和內容共用欄寬，圖錄與預覽貼齊頂端。最後一列四張是 64 卦的真實尾列，不用空資料補滿。學堂八站以四、二、一欄排列。
3. 介面色彩集中在卦畫、關係和狀態。控制元件採中性色，圖片保留完整原有色彩。金色卦畫、宋體與卦牌在首屏可辨識。
4. 搜尋數量按當前排列計算：64 在全卦為 1 筆，在十二消息為 0 筆。十二消息未搜尋時是 12 張。XP 與目標來自保存層，沒有樣本統計。
5. 未學過的狀態明寫「未開放」，未達標照實顯示 XP；不虛構成長率、占卜成果或學習人數。
6. 錯卦、綜卦、互卦圖例與牌框顏色一致，重疊關係保留合併文字標籤。卦名與上下卦另以 HTML 文字顯示，不依賴縮圖內的小字。
7. 手機導覽收進原生 dialog，支援 Esc 與焦點返回。圖錄兩欄；矩陣僅在自身容器橫向捲動，整頁不溢出。沒有新增進場動畫，減少動態效果模式可用。
