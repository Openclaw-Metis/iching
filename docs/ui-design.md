# 圖錄式介面設計與驗收

日期：2026-10-25。基準提交：`28d637a`。

## 設計方向

使用 Taste Skill 的 app screen 流程。選用 **True-black flat**，seed **379881689**，保留既有墨黑、古董金與 Noto Serif TC。品牌特色來自卦牌圖像、卦畫與經文；一般操作改用中性表面、系統字體與白底黑字主按鈕。

核心概念：六十四張卦牌成為可操作的圖錄。選中一卦，就在旁邊讀卦辭、觀察卦畫與錯綜互卦關係，再進入完整經文。手機保留兩欄卦牌與摘要列。

抽樣時有兩次重抽：

1. 外殼由 Ruled T-frame 改為 No sidebar。專案只有五個導覽入口，沒有帳戶或工作區切換，側欄會壓縮真正需要空間的卦牌。
2. 列表由 Count cards filters 改為 Table with tabs/filter bar。現有四種排列是觀看同一批卦的方式，不能虛構四組統計數字配合版型。排列控制搭配圖錄，沒有硬改成資料表。

## 專案自己的素材與限制

- 六十四張完成的 5:7 卦牌與統一牌背，沿用原有素材，不另生成圖片。
- 卦牌背景由上卦、下卦面板組合，可在八乘八矩陣比較。
- 文王卦序、上下卦、京房八宮、十二消息共四種排列。
- 錯、綜、互是實際卦象關係，預覽與連結皆由資料計算。
- 乾至未濟六十四卦的原典，依 `textOf(n)` 取用。
- 450 條白話經文，保留按需載入與原文切換。
- 三錢、親手分蓍、一鍵大衍與手動輸入的既有占卜流程。
- 每天固定一張今日卦，可記心得並自動保存。
- 八站、二十四課、八場考核，以實際八卦卦畫呈現站點。
- 修為、XP、每日目標與完成狀態皆取自本機資料。
- 本機保存、備份與離線機制照常；沒有新套件或資料結構變動。
- 溫故、收藏與行事曆提醒入口維持關閉。

## 截圖檢討

第一輪最明顯的三個問題是手機被舊媒體規則覆蓋成四欄、縮圖字級偏小，以及桌機預覽過高。已移除衝突規則，改為兩欄與 13px 說明，縮小預覽圖片並整理上下間距。同步修正奶油白與未實際載入的系統字型名稱警告。最後再縮短手機圖錄上方間距，並對齊學堂標題與內容。

依 app screen 的七個問題逐項檢查：

1. 最大區塊是實際卦牌；各頁的主要操作與資料先出現，沒有新增行銷式 hero。
2. 版頭和內容共用欄寬，圖錄與預覽貼齊頂端。最後一列四張是 64 卦的真實尾列，不用空資料補滿。學堂八站以四、二、一欄排列。
3. 介面色彩集中在卦畫、關係和狀態。控制元件採中性色，圖片保留完整原有色彩。金色卦畫、宋體與卦牌在首屏可辨識。
4. 搜尋數量按當前排列計算：64 在全卦為 1 筆，在十二消息為 0 筆。十二消息未搜尋時是 12 張。XP 與目標來自保存層，沒有樣本統計。
5. 未學過的狀態明寫「未開放」，未達標照實顯示 XP；不虛構成長率、占卜成果或學習人數。
6. 錯卦、綜卦、互卦圖例與牌框顏色一致，重疊關係保留合併文字標籤。卦名與上下卦另以 HTML 文字顯示，不依賴縮圖內的小字。
7. 手機導覽收進原生 dialog，支援 Esc 與焦點返回。圖錄兩欄；矩陣僅在自身容器橫向捲動，整頁不溢出。沒有新增進場動畫，減少動態效果模式可用。

## 經冊與畫卦（全站改版）

2026-10-27：依使用者要求以 design-taste-frontend（app screen 流程與 inspect）及 frontend-design 改版全站。使用者選定方向「經冊＋畫卦」、範圍一次改完全站、不生圖而以實際畫面截圖迭代，並允許使用 Three.js 與 GLSL。frontend-design 的逐區生圖步驟因此略過，以下的設計依據是改版前後的實際截圖。行為規格見 `docs/spec.md`「經冊與畫卦」。

### 概念

介面是一部墨底泥金的寫經冊。經文以直排金字配朱絲欄，白話與操作如橫排的注疏；卦是由下而上一爻一爻成形的，全站以這個動作作為招牌動態。競品測試：其他占卜或塔羅網站放進同一句話都不成立，因為直排卦辭、陰陽爻的畫法、先天八卦方位與太極路線都只屬於《周易》。

| 畫面 | 首要問題 | 這次的處理 |
|---|---|---|
| 卦殿 | 要找哪一卦？ | 頁首右側「畫卦尋牌」：點六爻找卦，金粉聚成爻，圖錄同步變淡並計數；預覽卦辭改為直排，短文分成兩三欄 |
| 卦牌 | 這一卦怎麼讀？ | 標題旁直排卦辭，手機改到標題下方；序卦改為上緣細線的文字連結 |

| 書卜 | 紀錄在哪裡？ | 沒有紀錄時以直排大畜大象（多識前言往行）配說明與兩個操作 |

### 視覺與動態系統

- 色彩沿用墨黑、古董金、朱紅與灰青，新增朱絲欄 `--rule`（`#5e3a31`）與較亮的 `--rule-hi`。一般控制元件維持中性表面與白底黑字主按鈕；導覽與分頁的目前項目以朱色細線標示。
- 字級：頁面標題 32px（手機 26px）、區段標題 20px 宋體、內文 16px、說明 14px，直排經文 19 到 27px。所有頁面從同一條左緣起，換頁時標題不跳位。
- 動態：主要區塊依序上升 16px 進場（間隔 70ms），卦畫由初爻依序長出，學堂已過路段依站序描出；金粉每爻 0.95 秒聚合、0.75 秒散去，靜止時每秒約 15 格閃爍，離開畫面或分頁隱藏即停止。減少動態效果時全部停用，金粉不載入，內容照常顯示。
- 金粉場景只有一個畫布，three 延遲載入，卦殿首屏不含 three、保存層與功能模組（首屏 133.5 KB／160 KB）。

### 截圖檢討

改版前（第 0 輪，`3ce1a7b`）：設計 6.5、可用 8、創意 6.5、內容 8，總分 7.1。問題依序是字沒有尺度（標題 28 到 32px、卦殿內文 13px、宋體只佔少數字形）、卦殿以外每頁都是「標題加灰色面板」（占卜首屏 40%、書卜 47% 空白，學堂八張等大站卡）、全站沒有任何東西由下而上動。

第 1 輪（改版後首次截圖）：學堂站點的卦畫被路線圖的 SVG 規則誤設為絕對定位、起卦畫面偏左且右半空、卡牌頁直排卦辭在 768 與 390px 被量成三行以上的標題、序卦兩塊卡片高度不一、書卜與各頁容器左緣不一致、課程開始畫面只有一行字。全部已修：選擇器改為只選直接子層、起卦置中並在爻旁註記、直排經文改用 blockquote 並在平板降為 24px、序卦改成文字連結、頁面統一左緣、課程與考核開始畫面列出步驟並標出本站八卦。

第 2 輪：設計 7.8、可用 8.3、創意 8.2、內容 8.5，總分約 8.1。短卦辭只剩細長一欄的問題以欄數平衡解決；學堂新使用者沒有任何資料色彩，改以朱色虛線標出下一段路線。
