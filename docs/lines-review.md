## 方法

1. **分批**：每批 8 卦，批次檔附該卦卦辭、彖傳、大象、六爻與小象全文（乾坤加文言與用九用六）、撰寫規則、欄位長度與輸出結構。Codex 與 agy 各在只放自己批次檔的資料夾裡執行，每方 4 批平行；agy 的提示寫明只讀檔、不執行指令。
2. **比對定稿**：逐卦並列 Claude、Codex、agy 三份稿與原文，逐條決定沿用 Claude 稿、取某一方的寫法，或參考兩方後改寫。
3. **自動檢查**：每批定稿都檢查長度、「」引文（以 `src/lib/text.ts` 的 `normalizeQuote` 正規化後能在 `易經_周易_原文.md` 找到）、破折號、保證語氣用詞，以及解說中把人標成「小人」。保證語氣的檢查只做提示：白話裡指出風險的警語（例如「太張揚就會招忌」）保留。
4. **交叉複審**：定稿連同經傳原文交兩方逐卦複審義理、引文、表達、語境轉譯與提醒，每卦判定 pass 或 revise，revise 須逐條列出鍵、欄位、嚴重度、問題與改寫建議。Claude 逐條決定採納、部分採納或不採納並記錄理由；採納時措辭由 Claude 統一，未必照抄建議。
5. **自動測試**：`src/data/lines.test.ts` 核對 450 個鍵齊全、長度在範圍內、每段「」引文能在原文找到且斷句位置一致、沒有破折號，並驗證 64 卦 × 64 種變爻組合的主讀與輔讀都找得到原文與白話，主讀的卦辭、爻辭、用九用六三種情況都實際出現（AC-05、AC-13）。卦辭另檢查判語：原文的「元亨」「亨」「利貞」「貞吉」「利有攸往」「利涉大川」「利見大人」「无咎」「吉」「凶」「悔亡」「无攸利」等，去掉白話裡「」引文後，仍要有對應的說法（例如「亨」要寫出亨通、通達或順暢，「无咎」要寫出沒有過失）。

## 撰寫原則

沿用 `docs/content-review.md` 的撰寫原則，並依這次複審補充：

- 引文一字不差，依本站底本用字與斷句，例如「莧陸夬夬」「井冽，寒泉食」「革言三就，有孚」「先庚三日，後庚三日，吉」。片段引文合規，但能引完整分句時優先引完整分句，例如「其吉，則困而反則也」「君子以明慎用刑而不留獄」。
- 卦辭的判語不漏譯：「亨」「利貞」「利有攸往」「利涉大川」這類判語要在白話裡說明，不能只放在引文裡。
- 不替讀者斷定現況，也不保證結果：提醒寫成「若……，可以……」「有助於」「比較有機會」，不寫「就會」「自然會」「終會」。
- 「貞凶」「貞厲」「貞吝」讀作固守下去會凶、有危險、有遺憾，不讀成守正也凶。
- 舊注有分歧時，採程頤、朱熹或王弼有根據的讀法；經傳本身沒有明說、出自注家的說法（例如文王事奉殷朝、九三想爭奪六二、借助外力渡險）標明「舊注」。
- 不給醫療、法律、投資的具體建議。无妄九五「勿藥有喜」寫明是比喻，並提醒真正的健康問題仍要就醫；中孚大象「議獄緩死」、旅大象「明慎用刑」點明是古代司法語境。
- 古代的性別、婚姻、身分、刑罰、戰爭與祭祀內容點明是古代語境，提醒轉譯成角色、責任與界線；疾病與刑傷（「臀无膚」「屨校滅趾」）寫明是描寫處境的意象。
- 數字與方位不當成應驗的預言：「七日得」「三歲不覿」「十年乃字」不換算成期限，「南征吉」「利西南」「西南得朋」不當成行程方位。

## 第一輪：三方比對定稿

Codex 與 agy 的 450 條初稿都完整收齊（agy 有一批把整份 JSON 印了兩次，取最後一份能解析的）。比對後改動 156 條、175 個欄位，其餘 294 條沿用 Claude 稿。改動條目依定稿主要採用的寫法分：

| 來源 | 條數 | 說明 |
|---|---|---|
| Codex | 31 | 取 Codex 的寫法 |
| 兩方共同指出 | 42 | Codex 與 agy 的稿都指出同一個問題，取兩方的共同處理 |
| agy | 0 | agy 單獨的寫法沒有被整條採用，但在 42 條共同處理中提供依據 |
| Claude 改寫 | 83 | 參考兩方後由 Claude 改寫，多數是去掉保證語氣 |

主要修正：

- **保證語氣與過度承諾**：「就能免於傷害」「好運才不會中斷」「該有的會回來」「必然混亂」等改為有條件或「比較有機會」。
- **古代語境**：夫妻反目、婦子嘻嘻、婦人吉夫子凶、娣與宮人、畜臣妾、從王事、朝貢享禮、西山祭享、輿尸等點明是古代家室、身分、祭祀或戰爭的語境，不把失和或失序歸咎於某一方。
- **疾病、刑傷與身體意象**：貞疾、遇毒、三日不食、左腿受傷、跛能履、眇能視等寫明是比喻，不用「瞎」「跛」形容人。
- **不直稱小人**：師上六、大有九三、遯九三、大壯九三、既濟九三等，原文的「小人」只在引文裡出現。
- **義理**：大人不限於權位（乾九二）、不習不是不用學習（坤六二）、食舊德不限於祖業（訟六三）、不家食不是吃閒飯（大畜卦辭）。

## 載入方式

白話只在需要時載入，不進卦殿首屏。`lines.json` 建置成獨立的雜湊檔，`loadLines()` 以 `fetch` 載入並快取。原本規格寫 `import()`，實測 Chromium 會記住載入失敗的動態模組，同一頁面按「重試」不會重新請求，因此改用 `fetch`，並已同步修改規格。
