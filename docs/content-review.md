# 六十四卦牌義撰寫與審訂

2026-10-24 由 Claude（主持、彙整）、Codex（GPT 系列）與 agy（Gemini 4 Argon）三方共同撰寫，內容存在 `src/data/content.json`，顯示在卡牌詳細頁的「牌義」分頁：關鍵詞、一句話牌義、整體牌義、白話導讀，以及事業與學業、感情與人際、行動與決策三項問事指引。

## 方法

1. **第一輪，三方各自獨立撰稿**：每批 8 卦，附上該卦的卦辭、彖傳、大象、六爻與小象（乾坤加文言）、序卦、雜卦原文。Codex 與 agy 用同一份撰稿說明各寫一份完整初稿；Claude 在讀到它們的稿子之前，先寫完自己的 64 卦初稿，三份才是真正各自獨立。
2. **比對定稿**：Claude 逐卦並列三份初稿，取各家所長整合成定稿。大致分工是：卦象與經傳脈絡取 agy 引文豐富的寫法，讓導讀能帶讀者認得原句；問事指引吸收 Codex 具體、可操作的建議；整體牌義與一句話牌義以 Claude 的簡潔版本為底。三方在初稿備註裡提出的誤讀風險，全部納入定稿。
3. **第二輪，交叉複審**：定稿連同原文再交給 Codex 與 agy 逐卦複審，檢查義理、出處、表達、古代語境的轉譯，以及指引是否可行；Claude 逐條判斷後修訂。
4. **自動檢查**：`src/data/content.test.ts` 會核對 64 卦齊全、各欄長度在規格內，以及每一段「」引文都能在 `易經_周易_原文.md` 找到，也禁止破折號。引文比對時逗號、句號可以互換，但斷句位置須與原文一致。

三方初稿存在 `docs/review/content-round1.json`，第二輪複審意見存在 `docs/review/content-round2.json`。

## 撰寫原則

- 引文一字不差，依本站底本用字，例如「先王以明罰敕法」「山附于地」「剝床以足」「巽在床下」「井冽，寒泉食」「革，已日乃孚」「反身脩德」「恐懼脩省」「治曆明時」。
- 不做絕對的吉凶斷言，遇到凶的爻寫出可以怎麼應對；不給醫療、法律、投資的具體建議。
- 古代的性別分工、身分與刑罰內容，在導讀中點明是古代語境，不讓讀者當成今日規範；指引則轉譯成角色、責任與界線。
- 數字與方位不當成應驗的預言：「七日來復」「至于八月有凶」「三歲不覿」不換算成固定期限，「利西南，不利東北」「南征吉」不當成行程方位。
- 不替讀者斷定現況，也不保證結果：指引寫成「若已有成果與支持，可以……」，而不是「事業正處於上升期」；寫「有助於」，而不是「自然就會」。

### 主要修正

**義理與取象**
- 乾：原稿把「開創、通達、適宜、正固」說成文言的解釋，改為這是通行白話解，文言則以善、嘉、義、事闡釋四德。
- 臨：「陽長之後必有陰消」把消長方向寫反，改為陽氣增長之後終將轉為消退。
- 復：「寒冬過後春雷萌動」錯置時令，改為冬至時陽氣初生、生機還藏在地底，與大象「至日閉關」相應。
- 大畜、小畜、大壯：「輹」不是車軸，改為車身與車軸之間的構件；「輻」改為車輻。
- 大有：九三「公用亨于天子」的「公」是公侯，不是「有公心的人」，原義與現代引申分開寫。
- 謙：上六「征邑國」征討的是自己的邑國，補上範圍並點明古代征伐語境；「六爻沒有凶辭」改為更準確的「沒有一句凶、悔、吝」。
- 恒、師、巽：「貞凶」不再直譯成「守正也凶」，改為「固執如此」或「固守下去」也凶，避免讀者以為守正有害。
- 節：上六「悔亡」不再解成「能悔改則悔恨消失」，改為苦節雖可免於悔恨，固守仍有凶險。
- 解：初六的「休養即無咎」缺乏依據，改依小象寫剛柔相接；六五補上小象「小人退也」的本義；六三補古代身分與車乘的語境。
- 坎：六四「納約自牖」不再坐實為「從窗口送進約信」，改寫成不講排場、在險境中尋求溝通。
- 咸：「咸少了心」是拆字式的延伸，改為歷來也從字形引申為無心之感，與彖傳「咸，感也」分開。
- 剝：「不利有攸往」不再解成「不宜有所作為」，改為不宜勉強進取、先穩固基礎，呼應大象「厚下安宅」。

**語境轉譯**
- 夬：一陰不再直稱「陰柔小人」；姤：「不是對女性的評價」改為「帶有古代婚姻與性別觀念，不宜用來評斷女性」；家人九三補上今日以合理規範與尊重維持家風；歸妹一句話牌義由「名分不正難長久」改為「釐清角色與承諾」。
- 豐：「王假之」不再加上「只有君王才能達到」，大象的斷案用刑補今日轉譯；明夷上六不再寫成「失德者終將傾覆」的報應保證。

**不斷定現況、不保證結果**
- 益、升、豐的指引不再開頭就斷定「資源正在增加」「事業正處於上升期」「業績聲望都好」，改為有條件的建議。
- 屯、需、同人、无妄、中孚、小過等卦，把「終能亨通」「就能渡過難關」「關係自然穩固」「守住低調就能平安大吉」改為「有助於」或附上條件；履、泰的一句話牌義也去掉保證語氣，萃的「備而不虞」語意不清，改為「戒備意外」。
- 剝的「不宜跳槽」、旅的「不宜做長遠定居決定」、明夷的「低調行事最安全」，改為依實際情況評估的建議；未濟的「堅持到最後一刻」補上停止條件。

**引文標點**
- Codex 指出「視履考祥」「有孚改命，吉」「射雉一矢亡」等引文省略或挪動了原文斷句。Claude 隨後寫了更嚴格的比對，又找出无妄大象、坎九二與六四、晉初六、家人彖傳與上九共 7 處，全部改回底本斷句，並把這項檢查加進測試。
